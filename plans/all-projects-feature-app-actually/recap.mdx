client-rendered. `ng build` prerenders 20 static routes, and each
`thoughts/<slug>/index.html` carries the essay text, real title, `og:` tags,
canonical URL, and `application/ld+json` before any JavaScript runs.

<Section id="key-changes" title="Key changes">

Server routes — the core SSR switch:

```ts
{
  path: 'thoughts/:slug',
  renderMode: RenderMode.Prerender,
  getPrerenderParams: async () => THOUGHTS.map((thought) => ({ slug: thought.slug })),
},
{ path: '**', renderMode: RenderMode.Client }, // desktop shell stays CSR
```

SeoService — written to the injected DOCUMENT so it lands in server HTML:

```ts
this.setJsonLd({
  '@context': 'https://schema.org',
  '@type': 'BlogPosting',
  headline: thought.title,
  datePublished: thought.date,
  author: { '@type': 'Person', name: SITE_NAME },
  // ...
});
```

Menu bar — hydration boundary now that the shell server-renders:

```ts
host: { ngSkipHydration: 'true' },
// ...
effect(() => {
  if (!isPlatformBrowser(this.platformId)) return;
  this.intervalId = setInterval(() => this.clock.set(this.formatTime()), 1000);
});
```
